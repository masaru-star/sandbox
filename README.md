# The Dumpster Fire

ここは、行き場を失ったコード片、夜中にハイテンションで書いた謎のスクリプト、そして「あとで綺麗にしよう」と放置された怨念が眠るサンドボックス（別名：デジタルゴミ捨て場）です。

## 免責事項
* ここにあるコードを実行してPCが爆発しても、私の髪が抜け落ちても、**一切の責任を負いません**。
* 動いたら奇跡、動かなくても平常運転です。
* 突然リポジトリごと消える可能性があります。

## 中に入っているかもしれないもの
1. 誰得の謎の便利ツール（便利とは言ってない）
2. 暇つぶし程度の低クオリティゲーム

## ゴミの投げ込み方
あなたの心の中にある「誰得コード」も、このゴミ捨て場なら歓迎される……かもしれません。
1. フォークする
2. 謎のスクリプトを追加する
3. プルリクエストを投げる（世界を少しだけカオスにする）

## 精度レーティング
1. 優良（オーパーツ / 奇跡の錬金術）<br>
概要： ゴミ捨て場にあるまじき、美しくメンテナンスされた高品質なコード。
2. 普通（深夜のテンション / 平常運転）<br>
概要： 動く。だが、なぜそれを書いたのか小一時間問い詰めたいコード。
3. 混沌（ダークマター / 禁忌の呪物）<br>
概要： 触る者すべてを絶望の淵に突き落とす、完全なるカオス。
